Human–Robot Teleoperation System

Real-time shared control system integrating Unity and ROS

Unity (C#) ROS (Python) Robotics Simulation

Overview

MSc dissertation project exploring shared-control teleoperation in robotics. The system combines human input with autonomous navigation in a simulated search-and-rescue environment.

🔧 Technical Architecture

  • Unity (C#) for simulation and UI
  • ROS (Python) for robot control and navigation
  • Real-time communication via rosbridge
  • RViz for debugging and visualisation
  • rosbag for data collection

🧠 Control System

Implemented a shared-control model combining human and autonomous inputs using a spring–damper system. A finite state machine manages dynamic role exchange between human, shared, and autonomous control modes.

📊 Evaluation

Conducted a user study with 15 participants. Analysed performance metrics such as collisions, trajectory smoothness, and control allocation to evaluate system behaviour.
