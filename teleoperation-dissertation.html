Human–Robot Teleoperation System

Unity (C#) · ROS (Python) · Shared Control · Robotics

Overview

This project was developed as part of my MSc Computer Science dissertation at the University of Nottingham. It explores shared-control teleoperation in robotics, combining human input and autonomous navigation in a simulated search-and-rescue environment.

🔧 Technical Architecture

  • Unity (C#) for 3D simulation and user interaction
  • ROS (Python) for robot control and navigation (move_base)
  • Real-time communication via rosbridge
  • RViz for robot visualisation and debugging
  • rosbag for data collection and replay

🧠 Control & System Design

A shared-control framework was implemented using a spring–damper model to combine human and autonomous inputs. A finite state machine (FSM) governed dynamic role exchange between human, shared, and autonomous control.

📊 User Study & Evaluation

A user study with 15 participants evaluated different feedback cues (haptic, egocentric, exocentric). Metrics such as collisions, trajectory smoothness, and control allocation were analysed.
